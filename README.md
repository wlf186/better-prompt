# better-prompt

**Prompt 双版本优化**：把现有提示词或自然语言需求，改写成两版可直接交给 AI 使用的 Prompt。

这是一个 Codex 项目级技能，核心是提示词优化规则。仓库只有文档和技能配置，无需安装项目依赖或启动服务。

## 能做什么

默认输出三个部分：

1. **优化版**：保留原目标和交付物，补全必要背景、约束、方法与输出要求。
2. **升级版**：围绕最终用途，探索更有价值的结果；新增范围会标为建议，仍遵守原有硬性约束。
3. **差异说明**：简要说明两版的关键区别，以及需要补充的信息。

两版提示词分别放在代码块中，便于复制到新会话。你也可以明确要求只输出一版，或使用其他格式。

适合优化已有 Prompt，或把写作、分析、编程等需求整理成清晰的任务说明。

## 快速开始

前提：已能使用支持本地技能的 Codex CLI 或 IDE 扩展。

克隆仓库并进入项目目录：

```bash
git clone https://github.com/wlf186/better-prompt.git
cd better-prompt
```

在该目录使用 Codex，输入：

```text
$better-prompt 帮我优化下面的提示词：
请根据我提供的季度数据，整理一份给管理层阅读的业务简报，控制在 800 字以内。
材料：[粘贴季度数据]
```

把示例中的任务和材料替换为你的实际内容。也可以直接请求“优化这个提示词”或“把这个需求写成 Prompt”，由 Codex 根据技能描述选择使用。

Codex 从项目的 `.agents/skills/` 目录发现技能；CLI 和 IDE 扩展支持通过 `$` 提及技能。若技能未出现，可重启 Codex 后重试。详见 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

## 更多用法

将任务描述转成 Prompt：

```text
$better-prompt 帮我把下面的需求写成可直接使用的提示词：
我需要一份 Python 项目的中文上手指南，面向新加入的开发者，
包括安装依赖、启动项目和运行测试。
资料：[附项目 README 和目录结构]
```

只要一版，并保留明确约束：

```text
$better-prompt 只输出优化版，保留“只改文案、不调整布局”的限制：
请帮我修改网站首页文案，让新访客更容易理解产品价值。
现有文案：[粘贴首页文案]
目标读者：[填写目标读者]
```

提供目标、受众、现有材料和硬性约束，有助于减少歧义。缺失信息若会改变任务方向，技能会先询问；其他缺失内容会用 `[待填：具体信息]` 标注。

## 优化思路

根据任务需要，从四个维度选择有实际收益的改进：

| 维度 | 关注点 |
| --- | --- |
| 速度 | 减少重复与返工，寻找更短、可靠的完成路径 |
| 高度 | 连接具体动作、交付物与最终用途 |
| 深度 | 补充相关的专业方法、证据与验收方式 |
| 广度 | 借用有帮助的跨领域思路，并落实到原有约束 |

简单任务只做必要增强，不要求每次用满四个维度。

## 使用边界

- 技能仅在包含它的项目目录及其子目录使用，不安装到用户级或系统级技能目录。
- 默认交付改写后的提示词；提示词中描述的命令或任务不会因此被执行，执行原任务需要明确要求。
- 保留用户指定的产品、语言、格式、长度、期限和权限边界。
- 不编造背景、数据、预算、指标、工具权限或已完成的验证结果。
- 升级版中的发布、持续监测、付费工具或对外操作，只能作为建议，不代表已获行动授权。
